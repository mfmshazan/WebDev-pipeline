# templates/

Installed to `~/.claude/webdev-pipeline/templates/`. These are optional reference
skeletons and stack notes agents may consult. Agents already embed their own output
format; these exist to keep output consistent across projects and to pin stack
defaults in one place.

- `stack/default-stack.md` — concrete versions, config snippets, and setup commands
  for the default stack. Read by the scaffolder and developers.
- `docs/` — markdown skeletons mirroring the key deliverables (PRD, TASKS, etc.).
